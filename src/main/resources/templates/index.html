Sobre o Projeto

DevOps Homestead é uma aplicação web desenvolvida com Spring Boot para ajudá-lo a organizar melhor sua vida doméstica. Com duas funcionalidades principais, você consegue gerenciar seus afazeres e controlar suas compras de forma simples e eficiente.

Recursos Principais:

  • Crie, edite e delete tarefas com facilidade
  • Defina prioridades e prazos para suas tarefas
  • Acompanhe o status de cada atividade
  • Mantenha uma lista de compras com preços
  • Calcule gastos em tempo real
  • Interface responsiva para todos os dispositivos
  • Alertas de sucesso e erro em tempo real

Tecnologias Utilizadas:

Spring Boot 4.0 JPA/Hibernate PostgreSQL Thymeleaf Bootstrap 5 Docker
